# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
**Private vulnerability reporting** entry on this repository's Security page.
Include the affected revision, platform, reproduction steps, impact, and any
suggested mitigation you have tested.

Do not attach model weights, access tokens, signing material, private prompts,
or conversation data. A small synthetic reproducer is preferred.

The maintainers will acknowledge a valid report through GitHub, investigate it
privately, and coordinate disclosure after a fix is available. This policy does
not promise a particular response time or support window while Minirun remains
a developer preview.

## Supported versions

Only the current public `main` branch is actively evaluated during the
developer-preview phase. Older commits and private research snapshots are not
supported releases.
